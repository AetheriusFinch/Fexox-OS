Fexox OS исходный код / Source Code

Операционная система независимая от Linux, с GUI, ориентированная для персональных компьютеров. Проект создан с целью создания простой, быстрой, открытой системы. Если людям будет интересно, проект будет вести разработку как серьезная операционная система для полноценного использования. Проект не является учебным. Документация по устройству ядра операционной системы Fexox находится в директории Documentation.

ОБ Fexox OS:
-Монолитное ядро
-Архитектура x86_64 (64 bit)
-ФС: FAT32, FHFS
-Планировщик задач: CFS-подобный (В будущем будет заменен на кастомный)
-library c: Musl (usermode), klibc (kernel mode)
-Стадия разработки: Alpha4
-Интернет через usb-модем, есть ip, tcp, dns
-Системных вызовов: 175 (Стараются придерживаться стандартам POSIX)
