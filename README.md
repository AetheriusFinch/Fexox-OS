Fexox OS исходный код

Операционная система независимая от Линукс, с GUI, ориентированная для десктопа. Проект создан с целью создания простой, быстрой, открытой системы. Если людям будет интересно, проект будет вести разработку как серьезная операционная система для полноценного использования. Проект не является учебным. 

ОБ ОС:
-Монолитное ядро
-Архитектура x86_64 (64 bit)
-ФС: FAT32 (В будущем будет заменена на собственную более современную)
-Планировщик задач: CFS-подобный
-Стадия разработки: Alpha1
